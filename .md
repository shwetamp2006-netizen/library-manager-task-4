# Task 4 — Algorithms and Automated Testing

C++ library-manager extension covering searching, sorting, reporting, automated tests, and complexity analysis.

## Features
- Linear search by ID.
- Binary search by ID (sorts by ID before searching).
- Insertion sort by ID and bubble sort by title.
- Availability report.
- Unit tests for normal, boundary, and invalid cases.

## Files
`Book.h`, `Algorithms.h`, `Algorithms.cpp`, `main.cpp`, `tests.cpp`, `COMPLEXITY.md`.

## Build app
`g++ -std=c++11 -Wall -Wextra -pedantic main.cpp Algorithms.cpp -o library_manager`
Run with `./library_manager` (Windows: `library_manager.exe`).

## Run tests
`g++ -std=c++11 -Wall -Wextra -pedantic tests.cpp Algorithms.cpp -o library_tests`
Run with `./library_tests`. Expected output: `All tests passed (normal, boundary, and invalid cases).`
